# 周复盘缺失体罚

## 规则

每周日 22:00 前**没完成周复盘**:
- 周日晚上**禁止**任何娱乐(游戏 / 短视频 / 追剧)
- 必须额外**1 小时**用于反思本周:
  - 这周最大的 3 个成就是什么?
  - 这周最大的 3 个错误是什么?
  - 下周最关键的 3 件事是什么?
- 写满 500 字反思笔记

## 为什么

- 周复盘是**系统迭代**的入口,跳一次两周后就崩
- 缺失复盘的周最容易重复犯同样错误
- "反思 1 小时"看似重,但一周省下的时间超过 3 小时

## 实战记录

| 周次 | 是否完成 | 缺失时处置 | 备注 |
|------|----------|------------|------|
| 2026-W37 | ✅ | - | 周六晚完成 |
| 2026-W38 | ❌ | 通宵补 1.5 小时反思 | 太累直接睡了 |
| 2026-W39 | ✅ | - | - |
| 2026-W40 | ✅ | - | 提前写了大纲 |

## 心法

> 复盘不是奖励,是止损。

缺失 1 周的代价 = **下周的隐性低效**。体罚让下次更早动笔。
