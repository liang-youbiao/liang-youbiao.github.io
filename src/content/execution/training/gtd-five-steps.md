# GTD 五步法训练

## 训练目标

- [x] 掌握 5 步流程
- [x] 每天 15 分钟每周回顾
- [ ] 保持 inbox 每天清零

## 五步流程

1. **收集**(Capture):所有任务先扔进 inbox,不分类
2. **处理**(Process):逐条决定下一步动作
   - 2 分钟内能做完 → 直接做
   - 需要更多时间 → 委托 / 推迟 / 加入项目
   - 不需要 → 扔进垃圾 / 归档
3. **组织**(Organize):按"下一步动作 / 等待 / 将来 / 也许"归档
4. **回顾**(Review):每周一次完整清单 review
5. **做**(Engage):按优先级和情境(地点/精力/时间)执行

## 心法

> 大脑是用来想事的,不是用来记事的。

GTD 的核心不是工具,是**信任系统**。你必须相信系统不会丢东西,才能真正清空大脑。
