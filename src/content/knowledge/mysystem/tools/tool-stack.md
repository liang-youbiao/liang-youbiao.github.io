# 个人工具栈

> 工具是手段,不是目的。这份清单会随时间调整,但**选型逻辑**基本不变。

## 选型三原则

1. **本地优先**(Local First):数据落本地 Markdown,工具坏了也能迁移
2. **长寿**:选 5~10 年内大概率仍在维护的工具,不追新潮
3. **少而精**:同时维护的工具 < 10 个,多了就是负担

## 当前栈(2026)

| 场景        | 工具                  | 为什么是它                                   |
| ----------- | --------------------- | -------------------------------------------- |
| 写博客      | Vue 3 + vite-ssg      | 静态站点,GitHub Pages 免费,无后端维护       |
| 知识沉淀    | Markdown + 本地文件夹  | 纯文本 + Git 版本控制,10 年后还能读          |
| 任务/时间块 | 番茄钟 + 纸质周计划    | 不上 Todo 软件,降低切换成本                  |
| 训练记录    | 本地 JSON + 训练仪表盘 | 简单结构化,Git 管理,可视化做在站点里         |
| 文档同步    | GitHub 私有仓库       | 既是备份也是时间机器                         |

## 不用什么

- ❌ Notion / Roam 等 SaaS 笔记 —— 锁数据、贵、依赖网络
- ❌ 多 IM 切换 —— 微信 + 企微已经够,其他全归档
- ❌ 复杂密码管理器 —— 1Password 即可,不要堆多个

## 工具栈的迭代节奏

- 季度回看一次:哪个工具**不再被打开**就考虑替换
- 不要为"未来可能用得上" 提前装工具
- 新工具至少坚持 30 天再下结论,避免"新鲜感误判"
